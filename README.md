### About The Project

A React project built to explore GSAP and modern web animations.  
The project focuses on creating smooth animations, scroll-based effects, and interactive user experiences.

### Tech Stack

- **Frontend:** React, TypeScript
- **Animations:** GSAP
- **Styling:** Tailwind CSS

### What I Learned

- Creating animations with GSAP
- Working with GSAP timelines
- Implementing scroll-based animations
- Creating interactive web experiences
- Integrating GSAP with React
